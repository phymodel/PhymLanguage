# Oblique Projectile Motion

## Formula

$$
\boxed{
\begin{aligned}
\text{Horizontal velocity: } &v_{x}=v_0\cos\theta \\
\text{Vertical velocity: } &v_{y}=-v_0\sin\theta+gt
\end{aligned}
}
$$

$$
\boxed{
\begin{aligned}
\text{Horizontal displacement: } &x=v_0t\cos\theta \\
\text{Vertical displacement: } &y=-v_0t\sin\theta+\frac{1}{2}gt^2
\end{aligned}
}
$$
