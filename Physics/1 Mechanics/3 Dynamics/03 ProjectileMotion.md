# Projectile Motion

## Formula

$$
\boxed{
\begin{aligned}
\text{Horizontal velocity: } &v_x = v_0 \\
\text{Vertical velocity: } &v_y = gt = \sqrt{2gh} \\
\text{Resultant velocity: } &v = \sqrt{v_x^2+v_y^2} = \sqrt{v_0^2+(gt)^2} \\
\text{Angle: } &\tan\theta =\frac{v_y}{v_x}=\frac{gt}{v_0}=\frac{\sqrt{2gh}}{v_0}
\end{aligned}
}
$$

- Where $\theta$ is the angle between the combined velocity and the horizontal direction

$$
\boxed{
\begin{aligned}
\text{Horizontal displacement: } &x=v_0t \\
\text{Vertical displacement: } &y=\frac{1}{2}gt^2 \\
\text{Resultant displacement: } &s=\sqrt{x^2+y^2} \\
\text{Angle: } &\tan\alpha=\frac{y}{x}=\frac{gt}{2v_0} \\
\text{Equation of the trajectory: } &y =\frac{g}{2v_0^2}x^2
\end{aligned}
}
$$

- Where $\alpha$ is the angle between the resultant displacement and the horizontal direction.
