# Circular Motion

## Formula

$$
\boxed{
\begin{aligned}
\text{Linear speed: } &v=\frac{\Delta s}{\Delta t}=\frac{2\pi r}{T} \\
\text{Angular speed: } &\omega=\frac{\Delta\theta}{\Delta t}=\frac{2\pi}{T} \\
\text{Period: } &T=\frac{2\pi r}{v}=\frac{2\pi}{\omega} \\
\text{Linear speed and angular speed: } &v=\omega r
\end{aligned}
}
$$

$$
\boxed{
\begin{aligned}
\text{Centripetal force: } &F_n=ma_n \\
\text{Centripetal acceleration: } &a_n=\frac{v^2}{r}=\omega v=\omega^2 r=\left(\frac{2\pi}{T}\right)^2 r=(2\pi f)^2 r
\end{aligned}
}
$$
