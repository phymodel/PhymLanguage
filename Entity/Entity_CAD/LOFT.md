# LOFT

**变截面放样**：一组椭圆截面沿一条轴排开、截面之间连续过渡，两端自动封盖，产出一个闭合实体。

`EXT` 只能把一个**固定**截面拉伸出去（等截面柱体），`PATH_OPEN` + `REV` 只能绕轴**回转**；
而 3D 打印件里最常见的形状（头盖、脸、左右壳、脚掌、滑轮支架）都是「截面一路在变」的放样体 —— 这就是 `LOFT`。

> `LOFT x,y,z AXIS h=ax,ay[:cx,cy] h=ax,ay[:cx,cy] … [SEG n] [SUB k]`

## 参数

| 记号 | 含义 | 必填 | 默认 |
|---|---|---|---|
| `x,y,z` | 放样轴的**起点**（第一个截面的中心） | ✅ | — |
| `AXIS` | 轴方向：`X` / `Y` / `Z`（`AXIS` 字样可省略，与 `PATH` 的 `NORMAL` 同一套写法） | ✅ | — |
| `h=ax,ay` | 距离起点 **h** 处的截面：椭圆半轴 `ax`（沿轴第一个垂直基向量）/ `ay`（第二个） | ✅ ≥2 个 | — |
| `:cx,cy` | 可选：该截面中心相对轴的**平面偏移**（截面漂移时用） | ❌ | `0,0`（与轴同心） |
| `SEG n` | 每个截面的圆周采样段数 | ❌ | 32（3…512） |
| `SUB k` | 相邻两截面之间再细分 k 段（Catmull-Rom 平滑过渡） | ❌ | 1（= 直线过渡） |

## 语义

- 截面按 `h` **严格递增**排列（同值/倒退 = 错误，不猜顺序）；半轴必须 > 0。
- 两端生成平面封盖（圆心扇形三角化），结果是**闭合实体**，可以继续参与 `SUBTRACT` / `UNION` / `INTERSECT` / `SHELL`。
- 外法线朝外（轴方向 + 截面逆时针）；`SUB` 细分只改变光滑度，不改变两端尺寸。
- `SUB k` 用 Catmull-Rom 插值截面参数 `(h, ax, ay)`：`SUB 1` 是圆锥台式的直线过渡，`SUB 4…8` 接近鼓形/腰形曲面。

## 示例

**同一个零件，截面方向决定拓扑** —— MicroDuck 头盖是**拱形顶棚**（x–z 断面一道拱、沿长度铺开），
所以要沿**长度**排截面，每个截面是「半宽 W、半高 H」的椭圆：

```phymodel
// 41 个实测截面（此处只摘 6 个）：h 从前往后递增，h=ax,ay:cx,cy
DEF outerArch = LOFT 0,0,-0.0565 Z 0=0.005,0.0021:0,0.0009 0.0125=0.03154,0.02818:0,0.002 0.0525=0.042,0.0392:0,0.002 0.0925=0.04436,0.04236:0,0.002 0.1225=0.05399,0.04319:0,0.002 SEG 48 SUB 1
DEF zFloor = PATH 0,0,-0.07 Z -0.06,-0.06 0.06,-0.06 0.06,0 -0.06,0 EXT 0.14
DEF arch = SUBTRACT outerArch zFloor      // 切掉椭圆下半截 → 拱只到 z=0
```

（沿 **z 轴**排截面、每个截面是「x/y 半轴」的椭圆，做出来的是**封闭鼓形壳** —— 这是同一份零件
最容易踩的错路：包围盒能对上，拓扑完全不对。）

### 两个实战注意

1. **`cy` 不要留 0 去切平面**：椭圆的**最宽处**就在 `cy` 那个高度上。如果切割面正好落在那里
   （比如 `cy=0` 又用 z=0 的地板切），两者**相切**，布尔会切出一堆开口边。
   把头抬 2 mm（`cy=0.002`、`ay` 相应减 2 mm），脚宽只差 0.05 mm，切出来就是干净的。
2. **截面密的时候用 `SUB 1`**：截面本身每 1…4 mm 一个已经足够密，Catmull-Rom 的过冲反而会把
   表面鼓出去（头盖实测：`SUB 3` 比 `SUB 1` 体积多 8 %）。

```phymodel
CAD()
.name("RoundedCapShell")
.mesh(commands: [
    // Ø60 → Ø92 → Ø70 的鼓形（沿 Z，30 mm 高），先放样出实体，再抽 1.2 mm 壁、去掉底面
    "DEF cap = LOFT 0,0,0 Z 0=0.030,0.026 0.015=0.046,0.040 0.030=0.035,0.030 SEG 48 SUB 4",
    "DEF capShell = SHELL cap 0.0012 OPEN z min",
])
.material(red: 0.95, green: 0.55, blue: 0.15, opacity: 1, roughness: 0.6, metallic: 0.0)
.physic(mass: 0.05, staticFriction: 0.6, dynamicFriction: 0.4, restitution: 0.2, mode: .kinematic)
.position(x: 0.0, y: 1.5, z: 0.0)
```

## 限制

- 截面目前只支持**椭圆**（含圆）；截面中心可以逐层偏移（`:cx,cy`），但不支持逐层**旋转**（斜截面）。多边形/自由曲线截面请先用 `PATH` 系命令，或用 `SOLID_FORMULA` 的隐式方程。
- **椭圆 ≠ 超椭圆**：有机外壳的断面常常是「比椭圆更饱满」的超椭圆（MicroDuck 头盖实测指数 p ≈ 2.8）。
  只支持椭圆时，脊高与脚宽可以逐点对齐，但**半高处的肩线会偏窄**（头盖实测最多差 5 mm）。
  待办：给截面加一个「指数 p」（`h=ax,ay:p`）或允许**引用 `PATH` 的轮廓点列**做自由截面放样。
- 不支持沿**曲线**脊线放样（截面只能沿直线轴排开）；那条路要用 `EXT_Bezier` / `EXT_BSpline` 的扫掠。
- 两端封盖是平面；要斜切/开口用布尔命令，或 `SHELL … OPEN`。
- 实现与自测：`PhyModel_Web/src/dsl/cad/loft.ts`、`npm run test:loft`（水密性、体积、包围盒、记号错误）。
