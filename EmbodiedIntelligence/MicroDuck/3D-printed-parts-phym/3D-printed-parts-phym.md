# MicroDuck 3D 打印件（phym 版）

把 [`vla-trainer`](../../../../vla-trainer/vla-hardware/3D-printed-parts/3D打印缝合怪版/stl模型) 里那套
**缝合怪版 MicroDuck** 的 3D 打印件，用 **phym 代码**重新表达：零件不再是二进制 STL，
而是一段可 diff、可参数化、可复算的建模命令。

```text
phym 代码（本目录）  ──PhyModel / PhyModel_Web 渲染──▶  ⚙︎ 设置 → 导出实体  ──▶  STL / 3MF  ──▶  vla-trainer 切片打印
```

方向是**单向**的：本目录是零件的**源**，`vla-trainer` 里的 STL 是**产物**。改尺寸就改 phym、再导一次，
不要把导出的 STL 拿回来当输入（那等于把源文件换成编译产物，改不动也 diff 不出来）。

## 为什么不用外部模型资产（`ModelURL()` 已删除，2026-11）

`ModelURL()` 曾是「模型自带几何、`.material()` 不生效、量纲来自文件」的通道 —— 它把外部 `.usdz` 当成
一等实体，**现已从 DSL 整体删除**（理由：破坏可 diff / 可复算、破坏可导出、破坏「单位只有一个来源」，
见 `PhyModel_Web/README.md` 的「为什么删掉 `ModelURL()`」一节）。

这里要的本来就是相反的东西：零件由我们建模、尺寸由我们掌握、颜色/材料由 DSL 声明。所以走 `CAD()` 命令栈
—— 本目录就是零件的**源**，`vla-trainer` 里的 STL 是**产物**。

## 单位与轴向（导出时必须对齐）

| 环节 | 单位 | 朝向 |
|---|---|---|
| phym DSL（`.position()` / `.mesh()` / CAD 命令） | **米** | Y 朝上（引擎轴） |
| STL（无单位，切片软件按毫米读） | 导出时按所选单位换算（默认 ×1000） | **固定 Z 朝上**：导出时自动绕 X 轴 +90° |
| 3MF（`<model unit="millimeter">`） | 声明毫米，数值同为毫米 | 同上（3MF 规范只认 +Z） |

所以：**实测 30 mm 的直径写成 `0.015` 的半径**。单位是导出面板里的选项（默认「毫米 mm」）；**轴向不用选**
—— STL 按 3D 打印约定、3MF 按规范都只能是 Z 朝上，由 `PhyModel_Web/src/dsl/export/upAxis.ts` 的格式表钉死
（`applyPrintAxes` 绕 X 轴 +90°，det = +1，零件不会被镜像；早先那个「Z 轴朝上」勾选框已删除）。
导出的文件直接能进 BambuStudio（与 `3D打印缝合怪版/缝合怪摆盘.3mf` 同一套口径：`unit="millimeter"`、
每个零件一个独立对象，可分别设材料）。

## 导出步骤

1. 打开本目录（Web 查看器：📁 选文件夹 / 原生：文档库）；
2. 3D 视口里出现零件 → 点对话面板左下角 ⚙︎；
3. 「导出实体」：目标 = 某个零件（导出**该零件自身网格**，与原生 STL 导出同口径）或「整个场景」；
4. 单位 = 毫米 mm（轴向不用管：STL / 3MF 导出时自动转成 Z 朝上）→ `Export Binary STL` / `Export ASCII STL` / `Export 3MF`。

> Web 端三个按钮的编码逻辑在 `PhyModel_Web/src/dsl/export/`（`stl.ts` / `threeMf.ts`，单位在 `units.ts`，
> 格式与朝上轴的对照表在 `upAxis.ts`），
> 自测：`npm run test:export`（31 条断言：面数、法线、毫米换算、Y→Z 映射是纯旋转 `det=+1`、ZIP 结构、CAD→STL 全链路）。

## CAD 能力：`LOFT` + `SHELL` 已补齐

曲面件（上表 🔴 的 15 件）卡在两条命令上，现在都有了（Web 端先行，规格已进
[`Entity/Entity_CAD/LOFT.md`](../../../Entity/Entity_CAD/LOFT.md) 与
[`Entity/Entity_CAD/SHELL.md`](../../../Entity/Entity_CAD/SHELL.md)）：

| 命令 | 干什么 | 写法 |
|---|---|---|
| `LOFT` | **变截面放样**：一组椭圆截面沿轴排开、连续过渡、两端封盖 | `DEF s = LOFT 0,0,0 Z 0=0.030,0.026 0.015=0.046,0.040 0.030=0.035,0.030 SEG 48 SUB 4` |
| `SHELL` | **抽壳**：向内偏置出等壁厚壳体，`OPEN` 去掉一端的端面做成敞口 | `DEF w = SHELL s 0.0012 OPEN z min` |

自测（`PhyModel_Web` 仓）：`npm run test:loft` —— 32 条断言，覆盖水密性（每条棱恰好被两个面共用）、
体积（圆台/圆柱解析值）、细分只改光滑度、记号错误被拒、圆柱壁厚实测 1.200 mm、`OPEN` 语义、
闭合实体的「双层封闭壳」警告，以及 `LOFT → SHELL → 导出 STL（毫米）` 的整条链路。

仍缺的次要项：螺纹（M2.5 螺丝柱）、变半径圆角、「截面草图」的一等公民表达（现在轮廓点列只能手抄）。

其余两项状态：**原生 PhyModel** 的 CAD 命令集暂无 `LOFT` / `SHELL`（同一份 `.phym` 在原生端会报未知命令）；
Web 端的 `LOFT` 截面目前只支持椭圆，沿曲线脊线的放样还得用 `EXT_Bezier` / `EXT_BSpline` 扫掠。
