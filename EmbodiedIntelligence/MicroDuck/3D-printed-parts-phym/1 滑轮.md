# 滑轮（Pulley）

> 一件一页：本页是 **滑轮** 这个零件自己的入口（讲义 + 场景）。整套零件的总览在
> [`3D-printed-parts-phym.md`](./3D-printed-parts-phym.md)；其余零件见文末「零件入口」。

MicroDuck 的 TPU 打印件之一：绕自身轴转的导轮（绳/带从槽里过）。它是这套零件里
**唯一一个回转体**，所以建模路径与壳体件完全不同 —— 圆盘 + 布尔 + 环槽，不需要 `LOFT`。

## 实测（来自原 STL）

| 项 | 值 |
|---|---|
| 外形 | **Ø30.0 × 7.60 mm** |
| 轴孔 | **Ø8.8 mm**（实测内缘 r = 4.40） |
| 轮缘绳槽 | 外缘 r 12→15 之间被削掉 z 0.49…7.11 那一段（真件是 V 槽） |
| 材料 | TPU（软料） |
| 原件网格 | 27,216 三角面 |

## 怎么建出来的

```phymodel
DEF body   = PATH_FORMULA 0,0,0 Z (x)^2+(y)^2=0.015^2 0.02 EXT 0.0076
DEF bore   = PATH_FORMULA 0,0,0 Z (x)^2+(y)^2=0.0044^2 0.01 EXT 0.02
DEF withBore = SUBTRACT body bore
DEF groove = SOLID_FORMULA 0,0,0 ((x^2+y^2)^0.5-0.015)^2+z^2-0.003^2=0 0.02 40
DEF pulley = SUBTRACT withBore groove
```

- 圆盘与轴孔都用 `PATH_FORMULA`（隐式轮廓 + 拉伸），两个 `SUBTRACT` 分别挖孔和切槽；
- **槽型是近似**：真件是 V 槽（带角度、带底径），这里用一圈 R3 的环槽代替。
  要精确就得先量出 V 槽的两条斜边 —— `PATH_OPEN`（开口轮廓 + 绕轴回转）才是它的正解，
  这件的槽型确认之后再改。
