# 头盖（HeadCover）

> **按「拱形顶棚」拓扑重做完成。** 上一版是「LOFT 同心椭圆 + SHELL」，做出来的是一个**封闭鼓形壳** ——
> 那是拓扑错误（不是尺寸误差），在 Viewer3D 里一眼就能看出来。这一版把原件的真实拓扑拆成了
> **40 条命令**：外拱放样 → 切地平面 → 减内腔 → 一刀切出开口端 → 开侧窗 → 3 条通槽 + 5 条通风槽
> → 内侧三根螺柱（Ø6.8 竖柱 + Ø2.1 盲孔，孔口朝下）。
>
> **开口端（原件 y≈−60…−66）必须是空的 —— 这里踩过两个坑，都已修：**
> ① 内腔后端也内收 1.2 mm，端壁把大开口糊成一块实心板；
> ② 更隐蔽的一个：外拱剪 `backTrim`、内腔再剪「抬高 2 mm」的同款轮廓，两条轮廓都沿 X 拉伸 110 mm，
> 两个切面之间的落差就在开口里横出一块板（抬高 2 mm 是 2 mm 板，只抬高 0.5 mm 也还是一层膜）。
> **正解是一刀切**：先做壳（外拱 − 内腔），再用同一把 `backTrim` 把壳切穿。
> 判据是从开口端沿 +Y 打射线看第一条命中面：原件穿到 y≈+41…+56；两版带板的都停在 y≈−61…−65；
> 一刀切之后同样是 y≈+48…+55。
>
> **第三次修：内侧还差三根螺柱。** 以前被记成「后段两条内部加强肋 + 前脸中央一个螺柱凸台」，
> 逐点比对后确认它们是同一族的三根 Ø6.8 螺柱（Ø2.1 盲孔、孔口朝下），已经补进命令栈 ——
> 位置、量法、为什么以前会看错、以及外部旁证见下面[「三根螺柱」](#三根螺柱第三次修要补的东西)一节。

> 一件一页：本页是 **头盖** 这个零件自己的入口（讲义 + 场景）。整套零件的总览在
> [`3D-printed-parts-phym.md`](./3D-printed-parts-phym.md)；其余零件见文末「零件入口」。

MicroDuck 躯体部分最大的曲面件，盖在头壳上。它**不是**一个球冠、也不是封闭的鼓形壳，
而是一张**拱形顶棚**：x–z 断面是一道拱（两侧壁陡直落到 z=0），沿长度方向铺开、越往前越窄越矮，
底面全开（只有两条脚线落在 z=0 上），两侧长边各有一个大拱形开口，顶脊一排 5 条通风槽，
两侧壁各 3 条水平通槽，**内侧三根 Ø6.8 螺柱**（M2.5 自攻，拧在头部集成板上）。

## 实测（来自原 STL）

| 项 | 值 |
|---|---|
| 外形 | **91.76 × 122.69 × 46.34 mm**（x × y × z），体积 **29 139.5 mm³** |
| 原件网格 | 25 402 三角面，**严格水密**（边界边 0） |
| 壁厚 | 侧壁 **1.7 mm**、顶板 **1.2 mm**（沿 x 横切实测 1.67…1.75 mm；沿 z 顶板 1.17 mm） |

| 材料 | 躯体部分 · PLA |

断面每 1 mm 取一次（x–z 平面），记两个数：**半宽 W**（z≈0 处最宽）与**脊高 H**（x=0 处最高）：

| y (mm) | −66 | −60 | −40 | −20 | 0 | 20 | 40 | 50 | 56 |
|---|---|---|---|---|---|---|---|---|---|
| H（脊高） | 45.2 | 46.1 | 44.6 | 43.0 | 41.5 | 38.9 | 32.8 | 23.6 | 6.0 |
| W（半宽） | 54\* | 45.1 | 44.5 | 43.0 | 40.0 | 38.7 | 33.8 | 25.6 | 8.6 |

模型里由 `backTrim` 剪掉，只留顶脊那一条约 2 mm 的翻边。41 个截面的完整数据写在 `.phym` 的两条 `LOFT` 里（内腔那条末尾多一个延伸截面，见 ②）。

## 三根螺柱（第三次修要补的东西）

**怎么发现的**：把原件表面采 40 000 个点，逐点量到重建面的最短距离（重建面也采 40 万点做 KD 树），
再看哪些点离得 > 2 mm。除了「肩部略扁」那一大片（下面[已知偏差](#已知偏差当前命令集的天花板不是失误) 1）之外，
**恰好剩三块成块的缺料**，位置和形状都一样：竖直圆柱、中间一个孔。

| 位置 | 圆心 (x, y) | 柱外径 | 盲孔 | 柱底端面 z | 孔底 z | 孔深 |
|---|---|---|---|---|---|---|
| 后段 · 左 | (−39.0, −49.5) | Ø6.8（r 3.40） | Ø2.1（r 1.05） | 3.2 | 14.8 → 钻尖 15.8 | ≈12.5 mm |
| 后段 · 右 | (+39.0, −49.5) | Ø6.8 | Ø2.1 | 3.2 | 同上 | ≈12.5 mm |
| 前脸 · 中 | (0.0, +49.5) | Ø6.8 | Ø2.1 | 3.2 | 同上 | ≈12.5 mm |

量法：在 z 上按 0.2 mm、平面上按 0.1 mm 取浸入判定的格点（原件是严格水密的，`contains` 可靠）。
三处共同的形状：

- **竖直圆柱**：任意 z 截面都是「Ø6.8 圆环 + 中间 Ø2.1 孔」（32 边形截面，实测外径 6.8–6.9、孔径 2.1）；
- **孔口朝下**：Ø2.1 从柱底端面 z=3.2 往上通到 z≈14.8，再 1 mm 钻尖封底（轴线上 z<15.8 是空的）；
- **柱身一直长到拱形内顶面**：柱底那片 Ø6.8 环形端面悬空，靠顶面吊住；柱外缘离侧壁内表面约 0.5 mm。
  在后段，柱顶与内顶面熔在一起（该处内顶面 z≈17.5…31），前脸那根的内顶面在 z≈22。

**以前为什么会看错？** 上一版记的是「后段 y≈−48 / −50.5 处的两条内部加强肋、前脸中央的螺柱凸台」。
在 x≈−39 处沿 y 切片，看到的确实是**两条 1.75 mm 的竖壁**，位置正好在 y≈−48 / −50.5 ——
但那不是两条肋，而是**同一根柱子中间那个 Ø2.1 孔的两侧壁**（孔跨 y −50.55…−48.45）。
换成 z 向的水平切片就一目了然：一根圆管。所以三处不是「两个肋 + 一个凸台」，是**同一种零件做了三次**。

**外部旁证**：`橙色部分/头部集成板.stl` 与头盖在同一个坐标系里（x 同样 ±45.9、y 同样 −60…56.5），
它在**完全相同的这三个坐标**上各有一个 Ø6.8 / 中孔 Ø2.6 的对配件（z≈11…15.4）。
Ø2.6 过孔 + Ø2.1 底孔 = **M2.5 自攻螺丝**：螺丝从头部集成板一侧穿上来，拧进这三根柱子。
少了它们，头盖没有任何着力点 —— 这不是「可有可无的局部特征」，是装配面。

**补进去要多少料**：三根合计 **+1.74 cm³**（19 902.8 → 21 640.9 mm³，按导出的 STL 三角面算）。
所以 19.9 与 29.1 之间的差**主要不是这里**，剩下的 ≈5.8 cm³ 仍然是肩部椭圆化（已知偏差 1）。

**怎么复核的**（想重跑一遍照这个顺序）：用 `PhyModel_Web` 的 CAD 命令栈**无头**跑 `.phym`
（`buildCadGeometry(commands)` → `encodeStlBinary(unit: 'millimeter', zUp: true)`，与面板导出同一个函数），
拿到毫米 / Z 朝上的 STL；再拿 `trimesh` 对原件做**双向**最近点距离 —— 原件表面采 4 万点量到重建面、
重建面采 4 万点量到原件面，两侧 p95 都在 3 mm 以内、且 > 2 mm 的点聚成哪几块就是还差什么。
补这三根之前，「> 2 mm」的团块是「两片肩 + 三块螺柱」；补完只剩两片肩。

## 怎么建出来的（40 条命令）

```phymodel
DEF outerArch     = LOFT 0,0,-0.0565 Z 0=0.005,0.0021:0,0.0009 … 0.1225=0.05399,0.04319:0,0.002 SEG 48 SUB 1
DEF cavityArch    = LOFT 0,0,-0.0565 Z 0.0012=0.01099,0.00699:0,0.002 … 0.1213=0.04811,0.04302:0,0.002 0.1245=0.04811,0.04302:0,0.002 SEG 48 SUB 1
DEF zFloor        = PATH 0,0,-0.07 Z -0.06,-0.06 0.06,-0.06 0.06,0 -0.06,0 EXT 0.14
DEF arch          = SUBTRACT outerArch zFloor
DEF backTrim      = PATH -0.055,0,0 X -0.02,0.0595 -0.02,0.071 0.044,0.071 … 0,0.06 0,0.0595 EXT 0.11
DEF shellRaw      = SUBTRACT arch cavityArch
DEF shell         = SUBTRACT shellRaw backTrim
DEF sideWindow    = PATH -0.055,0,0 X -0.003,-0.0149 0,0.0149 0.0021,0.0119 … 0,-0.0109 -0.003,0.0109 EXT 0.11
DEF part1         = SUBTRACT shell sideWindow
… 3 条 slot（通槽）+ 5 条 vent（通风槽），一路 SUBTRACT 到 headCover0
DEF bossL         = PATH_FORMULA -0.039,0.0032,0.0495 Y (x-0)^2+(y-0)^2=0.0034^2 0.02 EXT 0.05
DEF boreL         = PATH_FORMULA -0.039,0.0025,0.0495 Y (x-0)^2+(y-0)^2=0.00105^2 0.01 EXT 0.0133
DEF tubeL         = SUBTRACT bossL boreL
… 后段右（x=+39）、前脸中（x=0, Z=−0.0495）各一套，共 3×(柱 + 孔 + 减法)
DEF postL         = INTERSECT tubeL arch
… postR / postF 同款
DEF part9         = UNION headCover0 postL
DEF part10        = UNION part9 postR
DEF headCover     = UNION part10 postF
```

命令的意图（`.phym` 里每条都有注释）：

| 步 | 命令 | 干什么 |
|---|---|---|
| ① | `outerArch` | 外拱：41 个实测截面沿 Z 放样（每截面半宽 W、半高 H）。**这是「拱」的来源**，不是同心椭圆 |
| ② | `cavityArch` | 内腔：41 个实测截面 + 尾部 1 个**延伸截面**（`0.1245` → 原件 y=−68），半宽 −1.7 mm、半高 −1.2 mm。前端内收 1.2 mm（前脸原本就是封闭的），**后端越过外拱的尾端** |
| ③④ | `zFloor` → `arch` | 切掉椭圆的下半截：拱只到 z=0，脚是两条 1.7 mm 宽的边线 |
| ⑤ | `backTrim` | 开口端：y −60…−66 那段的脚线往上卷（实测 0→5.6→13→20.5→27.9→35.4→42.8 mm），剪掉多余的裙边 |
| ⑥ | `shellRaw` | 外拱 − 内腔 = 侧壁 1.7 mm / 顶板 1.2 mm 的拱形壳（开口端这时还封着） |
| ⑦ | `shell` | **一把刀同时切穿外壁和内壁**（`shellRaw − backTrim`）→ 开口端就是原件那种薄口。分成两刀（外拱一刀、内腔再一刀）无论抬高多少都会在开口里横出一块板，见文首说明 |
| ⑧⑨ | `sideWindow` → `part1` | 两侧长边的大拱形开口：30 个**实测点**组成的 y–z 轮廓，沿 X 打穿两壁 |
| ⑩–⑮ | `slot1..3` | 两侧壁各 3 条水平通槽：y −41…−31，z 10.25 / 15.25 / 20.25 起各 3.5 mm 高 |
| ⑯–㉕ | `vent1..5` | 顶脊 5 条通风槽：中心 x = 0、±9.1、±17.85，宽 2.8（中间 3.4），y −41…−53.6 |
| ㉖–㉞ | `bossL/R/F` → `boreL/R/F` → `tubeL/R/F` | 三根螺柱：Ø6.8 竖柱（柱底 y=0.0032、做到 y=0.0532）− Ø2.1 孔（y 0.0025…0.0158）。**孔先在柱子上减掉**，孔口朝下 |
| ㉟–㊲ | `postL/R/F` | `INTERSECT tube arch`：柱子上半截落在侧壁/顶板里，用外拱实体裁掉外皮以外的部分，剩下的自然与顶板熔成一体 |
| ㊳–㊵ | `part9/part10/headCover` | 三根依次 UNION 回壳体 |

为什么要「先做高再裁」：柱子**外缘**落在侧壁里（那里内顶面只有 z≈17.5），**内缘**离内顶面还有 6 mm
（那里内顶面 z≈31）—— 一个固定高度做不出「恰好到顶」，做矮了内缘会留一道原子里没有的缝，
做高了会从外皮里穿出去。用 `arch` 裁是唯一能一次到位的写法。`PATH_FORMULA` 的锚点就是圆心
（截面坐标是相对锚点的偏移，所以圆心写成 `(x-0)^2+(y-0)^2` 即可，圈半径按米写 0.0034 / 0.00105）。

两个建模要点（`.phym` 头部也有写）：

1. **`LOFT` 截面写成 `h=ax,ay:cx,cy`，`cy = +2 mm`**：椭圆最宽那一圈就落在 Y = +2 mm 而不是 Y = 0。
   否则地板切割面正好**相切**在椭圆最宽处，布尔会切出一堆开口边（试过，越切越碎）。脚宽因此只差 0.05 mm。
2. **`SUB 1`（截面之间直线过渡）而不是 `SUB 3`**：截面本身每 1…4 mm 一个、已经够密，
   Catmull-Rom 的过冲反而会把表面鼓出去（实测体积会多 8 %）。

## 已知偏差（当前命令集的天花板，不是失误）

1. **肩部略扁**：`LOFT` 的截面只能是**椭圆**，而原件的断面是**超椭圆**（实测指数 p ≈ 2.8）。
   脊高、脚宽都逐点对齐（< 0.1 mm），但 z 在半高处模型比原件窄 **最多约 5 mm**——
   正视图上看就是肩线略陡一点。正解是给 `LOFT` 加「自由截面 / 超椭圆指数」（已记进
   [`Entity_CAD/LOFT.md`](../../../Entity/Entity_CAD/LOFT.md) 的待办）。
2. **省掉的细节**：侧窗 / 通槽边缘有一圈宽约 1 mm 的小台阶（逐点比对后剩下的唯一成块差异，
   每处 ≤ 2 mm，集中在 (±35…40, y≈−26.5 与 +13, z 4…14)），以及前脸**底部中央那个约
   11 × 1.5 mm 的小口**（从 y=+80 沿 −Y 打射线，(x=0, z=4) 能穿到 y≈46，重建这里是实心的）。
   注意**前脸本身是封闭的**（原件 y≈54…56.5 的截面中间是实心的），所以内腔前端保留那
   1.2 mm 端壁不算错。（三根螺柱以前也在这张单子上，现已按实测补进命令栈。）
3. **CSG 网格的 T 形接点**：布尔操作的正确产物，但 `three-bvh-csg` 会在切割线上留下
   T 形接点（1e-4 量化下 7 518 条「边界边」里绝大多数是它；补螺柱之前是 5 103 条）。
   **切片没问题**——切片软件按三角面逐层求面交；若要「每条棱恰好两个面」，
   需要给布尔加一步顶点焊接（记进待办）。
4. **开口端是一道很薄的切口**：一刀切穿两壁，切口宽度就是「1.7 mm 壁厚斜切」的结果
   （约 0.5–1 mm，跟原件的薄口一致）。打印时是薄边，介意的可以在切片软件里设最小壁厚。
5. **螺柱孔口那一片零厚度的「膜」**：`three-bvh-csg` 的减法在「工具从操作数底面穿出」时，
   会在穿出平面给孔口补一片面（三根柱子都有，面积正是孔的截面 3.54 mm²，厚度 0）。
   厚度为 0，切片按层求交时不会填出材料，孔是通的、M2.5 自攻拧得进去；
   但**拿射线判「孔通不通 / 孔多深」时会先撞到这层膜** —— 量孔请用 0.1 mm 的逐层平面图。
   要彻底清掉得给布尔加一步去重面（同 3 的顶点焊接一起做）。

## 打印 / 交付

⚙︎ 设置 → 导出实体 → 目标＝`HeadCover` → 单位＝**毫米**（轴向自动 Z 朝上，面板里没有这个勾选框）→
`Export Binary STL`（单件）或 `Export 3MF`（整盘，每个零件一个对象，可在切片软件里分别设材料）。

导出后与原件**逐轴对齐**（X 宽 91.8 / Y 长 122.7 / Z 高 46.3 都同向），可以直接顶替原件
`stl模型/躯体部分/头盖.stl` 去打印。本页对应的导出文件是 `stl模型/躯体部分/头盖_phym.stl`
（10 198 三角面 / 21 640.9 mm³），原件保持不动。

装配面提醒：内侧那**三个 Ø2.1 底孔**是 M2.5 自攻螺丝的着力点，孔口朝下（朝底板一侧）。
切片时别把它们当「需要支撑的小孔」填掉 —— 孔口在 z=3.2 那一层有一片零厚度的膜（见已知偏差 5），
不影响成型；如果切片软件报了孤立小孔，用「最小壁厚 / 检测薄壁」那一项关掉即可。
